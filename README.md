# 대전경매 AI - Cost Saving

> Branch: `cost-saving`

대전 지역 아파트 경매 정보를 입력하고 기본적인 입찰 분석을 제공하는
웹 애플리케이션입니다.

이 브랜치는 프로젝트의 Cost Saving 구현을 담당합니다.

## 1. 프로젝트 목표

경매 물건의 기본 정보를 입력하면 프로그램이 직접 계산하여
가격 분석과 권장 입찰 범위를 제공합니다.

AI를 이용한 불필요한 계산을 줄이고,
프로그램에서 처리할 수 있는 부분은 프로그램에서 처리하는 것을
Cost Saving의 기본 방향으로 합니다.

## 2. 주요 기능

경매 물건의 다음 정보를 입력합니다.

- 사건번호
- 아파트명
- 주소
- 감정가
- 최저가
- 유찰 횟수
- 마이옥션 조회수
- KB시세

입력된 데이터를 이용하여 다음 결과를 계산합니다.

- 감정가 대비 최저가 비율
- KB시세 대비 최저가 비율
- 가격 매력도
- 예상 경쟁도
- 권장 입찰 범위

## 3. Cost Saving 방식

단순한 계산을 Gemini API에 요청하지 않고
프로그램에서 직접 처리합니다.

예를 들어:

감정가: 400,000,000원

최저가: 280,000,000원

감정가 대비 최저가:

280,000,000 / 400,000,000 × 100 = 70.0%

이러한 계산은 AI API 호출 없이 프로그램에서 처리합니다.

따라서 단순 계산에 발생하는 불필요한 API 사용을 줄일 수 있습니다.

## 4. 경매 분석 방식

### 감정가 대비 최저가

최저가가 감정가에서 어느 정도 수준인지 계산합니다.

### KB시세 대비 최저가

최저가와 KB시세를 비교하여 가격적인 매력도를 판단합니다.

### 가격 매력도

KB시세 대비 최저가 비율을 기준으로
가격 매력도를 구분합니다.

### 예상 경쟁도

마이옥션 조회수를 기준으로 예상 경쟁도를 구분합니다.

### 권장 입찰 범위

KB시세와 경쟁도 등을 이용하여
프로그램에서 권장 입찰 범위를 계산합니다.

## 5. Gemini AI 활용

사용자가 Gemini AI 종합의견을 요청하는 경우
경매 기본정보와 프로그램 계산 결과를 Gemini에 전달하여
종합적인 의견을 생성할 수 있도록 구성했습니다.

Gemini는 다음 내용을 중심으로 의견을 제공합니다.

1. 가격 측면의 장점
2. 예상 경쟁도
3. 주의사항
4. 권장 입찰 범위
5. 초보 투자자를 위한 최종 의견

## 6. Flask 백엔드

Gemini API를 브라우저에서 직접 호출하지 않고
Flask 서버를 통해 호출하는 구조로 구성했습니다.

구조:

Browser
↓
JavaScript
↓
Flask
↓
Gemini API
↓
Flask
↓
Browser

이를 통해 Gemini API Key를 서버 환경변수로 관리할 수 있습니다.

## 7. API

Gemini 분석 요청 API:

POST /api/recommend

브라우저에서 경매 정보를 JSON으로 전달하면
Flask가 이를 처리하여 Gemini API에 전달합니다.

## 8. 환경변수

Gemini API Key는 소스코드에 직접 작성하지 않습니다.

환경변수 이름:

GEMINI_API_KEY

API Key는 GitHub 저장소에 포함하지 않습니다.

## 12. 개발 방향

이 브랜치에서는 다음 원칙을 적용했습니다.

계산 가능한 작업

## 14. 주의사항

프로그램의 분석 결과는 입력된 공개정보를 기준으로 계산한
참고용 결과입니다.

실제 입찰 전에는 다음 사항을 별도로 확인해야 합니다.

- 권리분석
- 등기부등본
- 점유관계
- 미납 관리비
- 현장 상태
- 명도비용
- 실제 시세

프로그램의 권장 입찰가는 실제 낙찰이나 수익을 보장하지 않습니다.
