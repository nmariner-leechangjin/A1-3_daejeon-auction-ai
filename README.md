# 대전경매 AI

대전 지역 아파트 경매 물건의 공개 데이터를 입력하고,
프로그램 계산과 Gemini AI 분석을 통해 입찰 판단에 필요한 정보를 제공하는 웹 애플리케이션입니다.

## 1. 프로젝트 개요

대전 지역 아파트 경매 정보를 바탕으로 다음과 같은 분석을 제공합니다.

- 감정가 대비 최저가 비율
- KB시세 대비 최저가 비율
- 유찰 횟수
- 마이옥션 조회수
- 가격 매력도
- 예상 경쟁도
- 프로그램 권장 입찰 범위
- Gemini AI 종합의견

프로그램에서 직접 계산할 수 있는 수치는 코드에서 계산하고,
Gemini AI는 계산된 결과를 바탕으로 종합적인 의견을 생성하는 데 활용했습니다.

---

## 2. 프로젝트 목적

경매 초보자가 여러 수치를 직접 비교하지 않아도
입력된 공개정보를 바탕으로 물건의 가격 수준과 예상 경쟁도를
쉽게 확인할 수 있도록 하는 것을 목적으로 합니다.

또한 AI가 모든 계산을 수행하도록 하지 않고,
프로그램에서 처리할 수 있는 계산은 직접 처리하여
불필요한 AI API 호출을 줄이는 방향으로 구현했습니다.

---

## 3. 주요 기능

### 경매 물건 정보 입력

다음 정보를 입력할 수 있습니다.

- 사건번호
- 아파트명
- 주소
- 감정가
- 최저가
- 유찰 횟수
- 마이옥션 조회수
- KB시세

### 경매 기초 분석

입력된 데이터를 바탕으로 프로그램이 직접 계산합니다.

#### 감정가 대비 최저가

최저가가 감정가의 몇 퍼센트인지 계산합니다.

#### KB시세 대비 최저가

최저가가 KB시세의 몇 퍼센트인지 계산합니다.

#### 가격 매력도

KB시세 대비 최저가 비율을 기준으로 가격 매력도를 판단합니다.

#### 예상 경쟁도

마이옥션 조회수를 기준으로 예상 경쟁도를 계산합니다.

- 낮음
- 보통
- 높음
- 매우 높음

#### 권장 입찰 범위

KB시세와 예상 경쟁도 등을 프로그램에서 계산하여
권장 입찰 범위를 제공합니다.

---

## 4. Gemini AI 종합의견

프로그램에서 계산된 결과와 입력된 경매 정보를
Flask 백엔드에서 Gemini API로 전달합니다.

Gemini는 다음 항목을 중심으로 한국어 종합의견을 생성합니다.

1. 가격 측면의 장점
2. 예상 경쟁도
3. 주의해서 확인해야 할 사항
4. 프로그램 권장 입찰 범위
5. 초보 투자자를 위한 최종 의견

Gemini가 제공하는 의견은 참고용이며,
실제 낙찰이나 투자 수익을 보장하지 않습니다.

---

## 5. 절약형 구현

이 프로젝트의 핵심 구현 방향 중 하나는
AI API 사용량을 불필요하게 늘리지 않는 것입니다.

모든 분석을 Gemini에게 요청하는 대신
프로그램에서 계산할 수 있는 항목은 직접 계산합니다.

### 프로그램에서 직접 처리

- 감정가 대비 최저가 비율
- KB시세 대비 최저가 비율
- 가격 매력도
- 예상 경쟁도
- 권장 입찰 범위

### Gemini에서 처리

- 계산 결과에 대한 종합적인 해석
- 가격 측면의 장단점 설명
- 경쟁도에 대한 설명
- 초보 투자자가 확인해야 할 사항
- 최종 의견

이를 통해 AI가 필요한 부분에 집중하도록 구성했습니다.

---

## 6. 브랜치 구성

프로젝트에서는 구현 목적에 따라 브랜치를 구분했습니다.

### api-main

Gemini API를 활용한 기본 구현을 관리하는 브랜치입니다.

### cost-saving

AI API 호출을 줄이고 프로그램 자체 계산을 적극적으로 활용하는
절약형 구현을 관리하는 브랜치입니다.

두 브랜치는 프로젝트의 API 활용 방식과 비용 절감 관점을 비교하고
개선 과정을 확인하기 위한 용도로 사용했습니다.
