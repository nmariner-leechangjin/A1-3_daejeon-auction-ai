# 대전경매 AI - Cost Saving

대전 지역 아파트 경매 정보를 분석하고 Gemini AI를 활용하여
초보자도 이해하기 쉬운 경매 종합의견을 제공하는 웹 애플리케이션입니다.

이 브랜치는 AI API 사용량과 비용을 줄이는 것을 목표로 개발한
Cost Saving 구현입니다.

## 1. 프로젝트 개요

경매 물건의 공개정보를 입력하면 프로그램이 직접 가격과 경쟁도를 계산하고,
필요한 경우 Gemini AI를 이용하여 종합의견을 제공합니다.

단순 계산까지 AI에게 맡기지 않고 프로그램에서 직접 처리함으로써
불필요한 Gemini API 호출을 줄이는 것을 목표로 합니다.

전체 흐름은 다음과 같습니다.

사용자 입력
↓
프로그램 자체 계산
↓
가격 분석 및 권장 입찰 범위
↓
Gemini 분석 요청
↓
Flask 백엔드
↓
Gemini API
↓
AI 종합의견 출력

### 경매 물건 정보 입력

다음 정보를 입력할 수 있습니다.

프로그램에서 다음 항목을 직접 계산합니다.

- KB시세 대비 최저가 비율
- 가격 매력도
- 예상 경쟁도
- 프로그램 권장 입찰 범위

## 3. Cost Saving 방식

이 프로젝트의 핵심은 프로그램에서 처리할 수 있는 계산과
Gemini AI가 처리해야 하는 분석을 분리하는 것입니다.

### 프로그램에서 직접 계산

다음 항목은 Gemini API를 호출하지 않고 프로그램에서 계산합니다.

- 감정가 대비 최저가 비율
- KB시세 대비 최저가 비율
- 가격 매력도
- 예상 경쟁도
- 권장 입찰 범위

예를 들어 감정가가 400,000,000원이고
최저가가 280,000,000원이라면

280,000,000 / 400,000,000 × 100 = 70.0%

과 같이 프로그램에서 직접 계산합니다.

이러한 단순 계산에 Gemini API를 사용하지 않습니다.

### Gemini AI에서 처리

Gemini는 계산 자체보다는 계산 결과를 바탕으로
사용자가 이해하기 쉬운 종합적인 설명을 생성합니다.

Gemini 분석 항목은 다음과 같습니다.

1. 가격 측면의 장점
2. 예상 경쟁도
3. 주의해서 확인해야 할 사항
4. 프로그램 권장 입찰 범위
5. 초보 투자자를 위한 최종 의견

따라서

계산은 프로그램,
해석은 AI

라는 역할 분리를 적용했습니다.

## 4. Flask 백엔드

Gemini API 키를 브라우저의 JavaScript 코드에 직접 넣지 않고
Flask 서버에서 Gemini API를 호출하도록 구성했습니다.

데이터 흐름은 다음과 같습니다.

Browser
↓
JavaScript
↓
POST /api/recommend
↓
Flask
↓
Gemini API
↓
Flask
↓
JSON
↓
Browser

이를 통해 Gemini API 키를 서버 환경변수로 관리할 수 있습니다.

## 5. 환경변수

Gemini API 키는 코드에 직접 작성하지 않습니다.

사용하는 환경변수 이름:

GEMINI_API_KEY

로컬 환경에서는 .env 파일을 사용할 수 있으며,
Render에서는 Environment Variables에 등록합니다.

API 키와 같은 민감한 정보는 GitHub에 업로드하지 않습니다.

## 9. API 구조

Gemini 종합의견을 요청하는 API입니다.

POST /api/recommend

브라우저에서 Flask 서버로 다음 정보를 전달합니다.

- case_number
- apartment_name
- address
- appraisal_price
- minimum_price
- kb_price
- failed_count
- views

Flask는 전달받은 데이터를 바탕으로 Gemini에게 분석을 요청하고
AI의 결과를 JSON 형태로 브라우저에 반환합니다.

## 10. 오류 처리

Gemini API 호출 과정에서 오류가 발생할 경우
Flask에서 예외를 처리하여 오류 내용을 반환하도록 구성했습니다.

이를 통해 API 오류가 발생했을 때
브라우저에서 단순한 화면 오류가 아니라
API 처리 과정에서 발생한 문제를 확인할 수 있도록 했습니다.

## 16. Cost Saving 핵심 정리

이 프로젝트의 비용 절감 방식은
AI가 할 수 있는 모든 작업을 AI에게 맡기지 않는 것입니다.

단순 계산
→ 프로그램에서 처리

가격 비율 계산
→ 프로그램에서 처리

경쟁도 계산
→ 프로그램에서 처리

권장 입찰 범위 계산
→ 프로그램에서 처리

종합적인 설명과 해석
→ Gemini 사용

이를 통해 Gemini API를 필요한 부분에 집중해서 사용할 수 있도록
구조를 설계했습니다.

## 17. 프로젝트의 한계

본 프로그램은 입력된 공개정보를 기반으로 한
참고용 분석 프로그램입니다.

실제 입찰 전에는 다음 사항을 별도로 확인해야 합니다.

- 등기부등본
- 권리분석
- 임차인 및 점유관계
- 미납 관리비
- 실제 현장 상태
- 수리비
- 실제 거래가격
- 명도 관련 비용
- 기타 경매 관련 권리관계

프로그램의 권장 입찰가는 참고용이며
실제 낙찰이나 투자 수익을 보장하지 않습니다.
